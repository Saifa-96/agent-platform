YAML 语法速查 —— K8s 清单专用

只为读懂和书写 K8s 清单服务，不是完整 YAML 教程。配合 第 4 课与 练习 0001 使用。

两种结构：映射和列表

# 映射（键值对）——对应 JSON 的对象 {}
name: nginx-pod
replicas: 3

# 列表（一串元素）——对应 JSON 的数组 []，每个 "-" 开启一个元素
containers:
  - name: a        # 元素 1 开始
    image: nginx   #   与 name 对齐 = 同一元素内
  - name: b        # 元素 2 开始（新 "-"）
    image: redis
核心规则　"-" 是列表项的起始标记，不属于它后面的键。元素内的后续键与第一个键列对齐即属于同一元素，不需要再写 "-"。

JSON 对照（最快的心智模型）

YAMLJSON 等价
- name: x[ { "name": "x" } ] —— "-" 就是数组里对象的花括号
key:（无值，下面缩进）嵌套对象或数组的开始
key: value{ "key": "value" }

K8s 清单的固定骨架

apiVersion: v1            # 哪个版本的 API（决定 kind 的合法集合）
kind: Pod                 # 对象种类：Pod / Deployment / PVC / Service…
metadata:                 # 这份档案自己的信息（名字、标签）
  name: nginx-pod
  labels: { app: web }     # 行内写法：小型映射可以写在一行
spec:                      # 期望状态：每种 kind 有自己的 schema
  ...

课程清单里反复出现的列表位

列表位为什么是列表见过的地方
spec.containerspod 可住多容器（1 主 + N sidecar）第 1 课 NAP 的三容器 pod
spec.volumespod 可声明多块盘第 1 课盘位、第 6 课 PVC
containers[].volumeMounts一个容器可挂多块盘同上
spec.template不是列表——是嵌套对象（pod 的模子）第 4 课 Deployment

三条铁律（踩一次记一生）

铁律 1　缩进只有空格，禁止 Tab。
铁律 2　对齐决定归属：image 与 name 同列才是一个元素；差一格就是另一个层级。
铁律 3　冒号后必须有空格：name: nginx 对，name:nginx 错（会被当成一个字符串）。
